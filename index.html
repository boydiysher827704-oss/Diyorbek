Railway Track Defect Detection

An object-detection model that flags railway track sections as defective or non-defective from a photo, to support (not replace) manual track inspection.

Open Live Demo View Project Evidence

Evidence snapshot

78.6% Test Recall

On a held-out test set of 112 images never used in training, the model correctly flagged 78.6% of real defects. Recall was prioritized over precision because missing a real defect is costlier than a false alarm.

Problem / user

Manual railway track inspection is slow, expensive, and prone to human error. The intended user is a track inspection team using this as a screening aid, not an automated pass/fail authority.

How it works

  • Inspector uploads a photo of a rail section.
  • A fine-tuned YOLOv8 model scans the image for defect patterns.
  • The app returns a defective / non-defective label with a confidence score for human review.

Limitation

A confirmed data check found that about 12.5% of test images have a near-duplicate in the training set, so real-world accuracy is likely somewhat lower than the reported test metric. Full details are documented in the repository's ISSUE_LOG.md.

Manual truth check: Corrected an earlier draft that described this project as "image classification" — the model was actually built and evaluated as an object detector (outputs a bounding box, not just a whole-image label), so the page text was updated to match.
