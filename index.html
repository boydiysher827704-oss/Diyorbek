Model Audit Benchmark

0.786 Test Recall

mAP50: 0.651 | mAP50-95: 0.383

Evaluated on 112 protected test images with baseline YOLOv8n (30 epochs). Defective recall reached 0.739 and non-defective recall reached 0.833, prioritizing safety by minimizing missed defects.

🎯

Problem / user

Manual railway track inspection is slow, expensive, and error-prone. Unnoticed cracks, corrosion, or surface defects pose severe safety hazards for railway operators and track inspectors, requiring automated detection.

⚡

How it works

  • 1 Image Input: Accept single railway track images (resized to 640x640 resolution).
  • 2 Object Detection: Run baseline YOLOv8n model to detect defects and predict bounding box locations.
  • 3 Defect Classification: Output bounding boxes with class labels (defective / non-defective) and confidence scores.
⚠️

Limitation

Perceptual hash analysis revealed ~12.5% data leakage (14/112 near-duplicate test images matching train data), making reported test metrics somewhat optimistic. Additionally, class imbalance (~72-78% defective) caused lower precision on non-defective tracks (0.489).
